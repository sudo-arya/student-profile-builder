# Arya Editorial Academic

Adapted from Arya Singh's single-page HTML/CSS reference. The imported Jinja version preserves the fixed red sidebar, numbered navigation, editorial typography, alternating ruled sections, and responsive collapse. Its typography uses local system fallbacks, so no external font or runtime dependency is required.

Profile identity, photograph, email, CV, social links, and research interests use normalized profile fields. Every visible ordered section becomes a numbered block; semantic and arbitrary custom types share a generic Markdown renderer, so missing conventional sections create no dead links. Theme switching is intentionally disabled because the source design is light-only. The production template has no runtime dependency on `ta designs/`.
