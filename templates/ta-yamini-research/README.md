# Yamini Research Systems

Adapted from Yamini Chandana's complete React/Vite reference. The production version deliberately uses Jinja so distributed users do not need Node, npm, React, or Vite. The authored `src/styles/index.css` and `tokens.css` are copied into the template, while React's hardcoded data/components are mapped to normalized profile fields, ordered Markdown sections, and small dependency-free navigation/theme scripts.

The typographic axis labels, research-card surfaces, portrait treatment, compact header, responsive navigation, animations, and complete light/dark palette remain recognizable. Normalized identity fields, optional photo/CV/social links, interests, and all ordered visible sections are dynamic. Arbitrary custom sections use the same card fallback, while the teaching table becomes labelled stacked rows on narrow mobile screens. There is no runtime dependency on the reference folder.
