# Balaji Tailwind Portfolio

Adapted from Athinagaram Shree Balaji's single-file static design. It remains a responsive, card-based site with sticky navigation, mobile menu, rounded identity controls, and complete light/dark styling. The original Tailwind utility presentation has been reproduced in self-contained local CSS; no CDN, font download, or external runtime dependency is required. Font Awesome was removed in favor of text controls.

Jinja supplies normalized identity fields and conditionally renders email, photo, CV, links, and research interests. Navigation and content are generated from all visible ordered sections, including arbitrary custom types; absent sections have no links. Sanitized Markdown HTML receives generic typography and horizontally scrollable tables. No files are loaded from the ignored reference folder.
